# Algorithms Toolkit (Java)
Merge sort, randomised quick sort, binary search, BFS/DFS, Dijkstra, topological sort (cycle detection),
LCS, 0/1 knapsack, edit distance, memoised Fibonacci, sliding window, two pointers.
Each is checked against a reference or known answer. Complexity is noted next to each function.

Run:  javac Main.java && java Main
